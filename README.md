# Data Cleaning & Preprocessing

## 📌 Project Overview

This project focuses on cleaning and preprocessing raw datasets using **Python and Pandas**. The main goal is to transform raw and inconsistent data into a clean, structured, and analysis-ready dataset.

## 🎯 Objectives

* Handle missing values
* Remove duplicate records
* Correct data types
* Clean inconsistent data
* Detect and handle outliers
* Standardize data
* Prepare data for analysis and machine learning

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Jupyter Notebook**
* **Matplotlib**
* **Seaborn**

## 🔄 Data Cleaning Process

The project follows these major steps:

1. Load the dataset
2. Understand the dataset structure
3. Check missing values
4. Handle missing values
5. Remove duplicate records
6. Check and correct data types
7. Identify inconsistent values
8. Detect outliers
9. Clean and transform the data
10. Perform final data validation

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/Gauravrajpoot9/Data-Cleaning-Preprocessing.git
```

Go to the project folder:

```bash
cd Data-Cleaning-Preprocessing
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Run Jupyter Notebook:

```bash
jupyter notebook
```
